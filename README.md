 # C# Inventory Management System

A desktop application built in C# utilizing Object-Oriented Programming (OOP) principles to streamline inventory tracking, stock updates, and item management.

---

## 🛠️ Tech Stack & Concepts

* **Language:** C# (.NET)
* **Architecture:** Object-Oriented Programming (OOP) — Inheritance, Encapsulation, and Polymorphism
* **Data Storage:** SQL Database
* **UI/Interface:** Windows Forms (WinForms)

---

## ✨ Key Features
Item Management: Perform CRUD operations (Create, Read, Update, Delete) on inventory records.
* **Stock & Validation Logic:** Automated validation checks for low stock thresholds and item availability.
* **Search & Filter:** Quick search functionality by item ID, category, or product name.
* **Data Persistence:** Load and save inventory states directly to disk/database across sessions.

---

## 🏗️ Technical Highlights

* Designed using modular class structures separating business logic from user interface handlers.
* Applied OOP principles to handle item categories, stock transactions, and data validation cleanly.
